# Showcase site

This folder is the Vite site behind https://ui.halaska.com and the home of the kit itself, `halaska-kit-v1.0.jsx`. See the [root README](../README.md) for what the kit is and how to use it.

```bash
npm install
npm run dev      # local showcase on http://127.0.0.1:3000
npm run build    # also regenerates public/llms.txt, public/halaska-kit.d.ts, public/source-map.json and copies the kit to public/halaska-kit.jsx
```
